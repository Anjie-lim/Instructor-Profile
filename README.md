# Angeline Marie L. Trayfalgar — Instructional Design Portfolio

A single-page GitHub Pages portfolio for an Instructional Designer / Trainer / AI-Enabled Learning Specialist.

## Files

- `index.html` — complete portfolio site
- `resume.pdf` — resume PDF

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `resume.pdf` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide the public Pages URL.

The site does not require a build system, framework, or external dependencies.
